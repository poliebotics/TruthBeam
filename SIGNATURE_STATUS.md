# Signature status for v1.1.0 and v1.2.0

The `v1.1.0` repository and navigation update, published on 7 September 2026, and the `v1.2.0` results-shelf update are **unsigned**, by owner decision.

The existing `SHA256SUMS` and `SHA256SUMS.asc` pair is retained byte-for-byte because it authenticates
the listed historical dataset, model, media, whitepaper, CID-manifest, and verification-bundle
artifacts. It does **not** authenticate the new `v1.1.0` repository text, liveness compiler, research
agenda, byte-exact recovery receipt, or site copy. The recovered NPY and block are not included in Git
or in the site overlay. `CID_MANIFEST.json`, the historical checksum manifest, and its signature remain
unchanged.

The preserved GitHub `v1.0.0` tag and release remain historical records and must not be replaced.
